# Tianyuan Xinshi · Heart Market

*A market in old Chang'an where comfort, clarity, fortune and inspiration are bought and sold.*

天元心市 — 问心入市，万念皆可交易。

[Play in browser](https://tiany-heart-market.onrender.com/) · [Project page](https://luoluo926.github.io/projects/tianyuan/) · [Repository](https://github.com/luoluo926/tianyuan-xinshi)

The project began as a *Fantasy Westward Journey*–style isometric MMO built on **GGE**, a Lua 2D game engine, and now ships with a small Node runtime that runs the same city, characters and sprites in a browser. You enter as a guest or an account holder, walk the streets of Chang'an, trade goods that stand in for feelings, read the market board, and eventually open a stall of your own.

The hosted build runs on a free instance that sleeps when idle; the first visit of the day can take up to a minute to wake, after which it loads normally.

## What is in the box

The repository holds three things that were originally separate: a general-purpose Lua engine, the game's own Lua content, and the browser delivery layer.

```
GGELUA/        Lua engine (GGE, GUI, GOL, bundled libs) plus the lua.exe launcher
XYQCS/         Game content and logic in Lua
  lua/地图       Map data and the 1001 Chang'an map
  lua/对象       Object model and base classes
  lua/战斗逻辑   Combat resolution
  lua/界面       Windows, widgets, login and lobby layers
  lua/网络       Networking
  assets/       Source scenes and character shapes
web/           Browser runtime
  server.js    HTTP server and JSON API
  public/      index.html, app.js, styles.css, precompiled assets
  tools/       Asset export scripts
render.yaml    Render blueprint for the hosted build
start-web.cmd  Windows one-click launcher
start-server.ps1  PowerShell launcher with port and host options
package-release.ps1  Builds a deployable archive
```

The engine is not a thin wrapper: `GGELUA/ggelua/GGE` carries rendering, timing, sprite and camera code; `GOL` implements RPC over sockets; `GUI` and `LIB/IMGUI` provide two complete widget toolkits.

## The browser build

`web/server.js` is a single Node file with no framework dependency. It serves the static front end, exposes a JSON API, and stores accounts on disk.

| Endpoint | Purpose |
| --- | --- |
| `/api/bootstrap` | Runtime flags, catalog and asset manifest |
| `/api/auth/guest` | Enter as a guest without registering |
| `/api/auth/enter`, `/api/auth/login` | Register or sign in |
| `/api/world` | Current map state and nearby entities |
| `/api/player/move` | Move the character |
| `/api/npc/talk` | Dialogue with a non-player character |
| `/api/player/save` | Persist role state |
| `/api/assets`, `/api/data-files` | Static catalog lookups |
| `/api/render/model` | Character model frames |
| `/api/preload/status` | Precompilation progress |

The front end keeps its own render loop on a full-screen canvas and never decodes `.map` or `.was` files at runtime. Those are converted ahead of time into PNG tiles, masks and sprite sheets under `web/public/generated/`.

## Running it

Node 18 or newer.

```bash
cd web
npm install
npm start
```

The server listens on <http://127.0.0.1:8080>. On Windows, `start-web.cmd` does the same thing from the repository root; `start-server.ps1 -Port 9000` changes the port and `-SkipPrecompile` skips the asset check.

`npm start` verifies the precompiled scene before serving: 840 map tiles, 818 masks, 47 NPC sprite sources and 17 playable character models with stand and walk frames. To rebuild them, run `npm run precompile`.

## Deployment

`render.yaml` describes a single Node web service rooted at `web/`, started with `npm start`. The hosted configuration sets `PRECOMPILE=0` and `STATIC_RUNTIME=1` so the service never tries to rebuild assets on boot, and points the health check at `/api/bootstrap`.

To produce an offline deployment archive instead:

```powershell
.\package-release.ps1
```

## Assets and storage

Binary game assets are tracked with **Git LFS** — PNG, JPG, `.map`, `.was`, audio and the engine DLL. A plain `git clone` leaves them as pointer files, so install `git lfs` first:

```bash
git lfs install
git lfs pull
```

The precompiled browser assets under `web/public/generated/` account for most of the repository's weight; the Lua sources are small by comparison.

Accounts live in `web/data/users.json` and are created at runtime. The file is generated by the server and intentionally not tracked — a fresh checkout starts with an empty account table.

# 天元心市

*古风长安里的心货买卖*

线上地址：<https://tiany-heart-market.onrender.com/>（免费实例空闲会休眠，首次打开可能需要等待约一分钟）。项目介绍页：<https://luoluo926.github.io/projects/tianyuan/>。

仓库包含三部分：通用 Lua 引擎 `GGELUA`、游戏本体的 Lua 内容与地图 `XYQCS`、以及把同一套场景搬到浏览器的 Node 运行时 `web`。

浏览器版的入口是 `web/server.js`，不依赖任何框架。运行 `cd web && npm start` 后访问 <http://127.0.0.1:8080>；首次进入可以选择访客模式，不必注册。

地图与角色资源以 Git LFS 托管，克隆前需要安装 `git lfs`。预编译后的地图块、遮罩与角色帧放在 `web/public/generated/`，运行时不再解析 `.map` 与 `.was` 源文件。

账号数据写在 `web/data/users.json`，由服务端在运行时创建，不纳入版本管理。

音乐与音效的来源记录在 `web/public/assets/audio/MUSIC_CREDITS.txt`，界面字体为马善政毛笔楷书（SIL OFL）。
